# データ構造

アプリケーションが扱うデータの形を、`nijo.xml` の `DataStructures` セクションに定義します。

データ構造から何が自動生成されるかは、ルート集約に指定する以下の属性の組み合わせで決まります。

| 属性                                         | 意味                                     | 主に生成されるもの                                         |
| -------------------------------------------- | ---------------------------------------- | ---------------------------------------------------------- |
| [IsStored](./020310_IsStored/index.md)       | データベースに永続化される               | EF Core エンティティ、新規登録・更新・削除処理、入力検証 |
| [IsQueryable](./020320_IsQueryable/index.md) | 画面や帳票から検索・照会される           | 検索条件、一覧検索処理、画面表示用データ                   |

| IsStored | IsQueryable | 生成されるもの                                                                                                                   |
| :------: | :---------: | -------------------------------------------------------------------------------------------------------------------------------- |
|    ○     |             | 永続化のためのモジュール                                                                                                         |
|          |      ○      | 検索のためのモジュール。各項目をどのテーブルから取得するかは手動で実装する                                                       |
|    ○     |      ○      | 永続化のためのモジュールと、テーブルと全く同じ形の検索のためのモジュール。きわめて単純なマスタデータなどを想定                   |
|          |             | Webサーバーとクライアントの間で共有される[構造体](./020330_Structure/index.md)                                                 |

IsStored 属性が指定されたデータ構造には、さらに以下の属性を指定できます。

* [UseSoftDelete](./020310_IsStored/020314_UseSoftDelete.md): 削除処理を論理削除にします。
* [IsGenericLookupTable](../020700_Constants/020703_GenericLookupTable.md): システムの運用中に値が追加削除される区分値（動的な定数）を格納するテーブルにします。

## 集約の種類

データ構造は、ルート集約とその子孫（Child, Children）からなるツリー構造で定義します。

| 種類                        | 説明                         |
| --------------------------- | ---------------------------- |
| **Root**（ルート集約）      | 集約の起点                   |
| **Child**（1対1子集約）     | 親に対して0または1件の子要素 |
| **Children**（1対多子集約） | 親に対して0件以上の子要素    |

キーの要否などは、指定した属性によって異なります。各属性のページを参照してください。
