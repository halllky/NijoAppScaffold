# 定数

アプリケーション全体で共有される値を定義します。
値をどこで管理するかによって、静的な定数と動的な定数に分かれます。

|          | 静的な定数                                                               | 動的な定数                                               |
| -------- | ------------------------------------------------------------------------ | -------------------------------------------------------- |
| 定義方法 | `Constants`、`StaticEnums` セクション | [汎用参照テーブル](./020703_GenericLookupTable.md)（IsStored 属性が指定されたデータ構造に IsGenericLookupTable 属性を指定） |
| 値の管理 | `nijo.xml`（ソースコード上にハードコード）                               | データベースのテーブル                                   |
| 値の変更 | ソースコードの変更・再デプロイが必要                                     | システムの運用中に追加削除できる                         |
| 用途     | 変わらない値・区分（性別・ステータスなど）                               | 運用中に変わりうる区分（国コード・分類など）             |
