# Nijo App Scaffold - 空テンプレート

nijo.xml から自動生成されるソースと、その格納先のプロジェクトだけを含むテンプレートです。
データベース接続、データの保存処理、Web API、画面は含まれていません。

## 含まれるもの

- **nijo.xml** : スキーマ定義。
- **Core.AutoGenerated** : C# の自動生成されたソースを格納するクラスライブラリ。
- **client** : TypeScript の自動生成されたソースを格納するフォルダ。依存パッケージは TypeScript だけで、開発サーバーや画面のライブラリは入っていません。

`Core.AutoGenerated/__AutoGenerated` と `client/src/__autoGenerated` の中は、自動生成のたびに上書きされます。
手書きのコードは別のプロジェクトやフォルダに置き、自動生成されたソースを参照してください。

## ソースの自動生成とビルド

nijo.xml を編集したら、`nijo generate` を実行するか、`nijo serve` で開かれる画面から自動生成してください。

- C# : このフォルダで `dotnet build` を実行します。
- TypeScript : client フォルダで `npm install` のあと `npm run tsc` を実行します。

## アプリケーションごとに作成するもの

自動生成されたソースはビルドできますが、それだけでは実行する入口がありません。次のものはアプリケーションごとに作成してください。

- 自動生成された抽象クラスを継承したクラス。実装が必要な抽象メンバーは、継承したクラスのコンパイルエラーで分かります。
- データの保存処理。自動生成される入力チェックを通したうえで、DbContext の SaveChanges など、Entity Framework Core の通常の方法で保存してください。
- Web API や画面など、自動生成されたクエリやコマンドを呼び出す処理。
