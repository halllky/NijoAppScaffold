## 1. 業務の概要

### 1.1 扱う業務

- 商品：外部の商品管理システムから日次で取り込むマスタ。このシステムでは登録しない。
- 入荷：商品の入荷を、明細つきの伝票として登録・修正する。入荷の明細ごとに在庫の残数量をもつ。
- 売上：商品の売上を、明細つきの伝票として登録・修正する。登録時に、古い入荷の明細から順に在庫を引き当てる。
- 在庫調整：棚卸しの差異、破損、返品などで在庫を増減させる。
- 従業員：ログインするユーザー。「権限区分」の入荷担当・販売担当・システム管理者を組み合わせてもつ。

### 1.2 画面

| 画面 | 内容 |
|---|---|
| P100 売上 | 売上の一覧検索 |
| P101 売上詳細 | 売上の新規登録・修正・閲覧 |
| P200 入荷 | 入荷の一覧検索 |
| P201 入荷詳細 | 入荷の新規登録・修正・閲覧 |
| P300 商品 | 商品の一覧検索 |
| P301 商品詳細 | 商品の詳細と在庫の増減の履歴 |
| P400 従業員 | 従業員の一括編集 |
