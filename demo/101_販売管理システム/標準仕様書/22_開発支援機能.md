# 22. 開発支援機能

開発環境でだけ使える機能を扱う。本番には現れない。

## 22.1 外部仕様

| ID | 仕様 | 確認方法 | 関連非機能要件 | 備考 |
|---|---|---|---|---|
| DEV-001 | 開発支援機能は、本番用のビルドと本番環境では、画面にも API にも現れない | 検査 | セキュリティ | 開発支援機能の API はログインせずに呼び出せるため |

## 22.2 開発者向け情報

### 開発支援機能の一覧

開発環境では、次の機能を使える。

- 画面上部のデバッグメニューから、DB を削除して作り直し、ダミーデータを入れる
- DB のテーブルの関係とデータを画面で確認する（DB ビューア）
- 画面の共通部品の動きを確かめる見本の画面
- API の一覧（Swagger）

### 本番に出さないための作り

- 画面：開発モードで動かしているときだけ、デバッグメニューと開発用の画面を登録する。
- サーバー：DB の作り直し・ダミーデータの生成・DB ビューアは Debug ビルドにだけ含める。DB ビューアは、さらに開発環境でなければ拒否する。API の一覧は開発環境でだけ有効にする。
- 本番に出す前に、Release ビルドと画面の本番用ビルドの結果で、これらが現れないことを確認する。
