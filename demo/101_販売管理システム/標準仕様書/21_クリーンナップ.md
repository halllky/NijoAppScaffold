# 21. クリーンナップ

古くなったデータを削除する処理「クリーンナップ」を扱う。他の章のデータの削除も、この処理の中で行う。何をどれだけの期間残すかは、案件で決め直すことを想定している。

## 21.1 外部仕様

| ID | 仕様 | 確認方法 | 関連非機能要件 | 備考 |
|---|---|---|---|---|
| CLN-001 | 処理「クリーンナップ」は、最後に操作してから一定時間が経ったセッションを削除する | 検査 | | 期限が過ぎたセッションは、削除される前でも無効として扱われる（SES-004）。ここで削除するのは、古い行の掃除のため |
| CLN-002 | クリーンナップは、定期的なジョブとして毎日起動する（JOB-006） | 検査（未実装） | | それまではクリーンナップを定期的に起動する仕組みはない |
| CLN-003 | クリーンナップを画面から実行できるのは、システム管理者だけである。ログインユーザーのいない呼び出し（ジョブ、バッチ）からは実行できる | 検査 | セキュリティ | |
